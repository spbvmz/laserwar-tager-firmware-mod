# LaserWar тагер — модификация прошивок ZOMBIE

Неофициальная модификация прошивок тагера LaserWar **V9.02.76.3** и **V9.02.82** для лазертага. Добавлено управление временем превращения в «Зомби» и смена ID тагера **без включения режима конфигурации**.

## Файлы

| Файл | База |
|------|------|
| `V9.02.76.3-rus_ZOMBIE.bin` | официальная V9.02.76.3 (рус.) |
| `V9.02.82-rus_ZOMBIE.bin` | официальная V9.02.82 (рус.) |

## Что добавлено

- **Время превращения в «Зомби»** — команда `C5`: задаёт полное время от смерти до превращения в зомби (0…60 с). Фраза и рычание как в оригинале. С пульта: меню **Девайсы → Зомби → Время**.
- **Смена ID тагера** — команда `C6`: записывает ID игрока (0…125) в RAM и EEPROM без режима конфигурации. С пульта: меню **Девайсы → ID тагера**.

Заводские режимы игры и остальная логика тагера не менялись намеренно (кроме указанных команд).

## Управление с пульта

Нужна модифицированная прошивка **«Умный пульт Про v.1»**:

https://github.com/spbvmz/laserwar-smart-remote-pro-v1-mod

Без этого пульта команды `C5`/`C6` можно отправить другим ИК-передатчиком в формате MilesTag, но меню рассчитано на указанный мод.

## Оригинальные прошивки

Официальные прошивки тагера скачиваются с сайта производителя:

https://laserwar.ru/firmware-for-hardware/

В этом репозитории **нет** оригинальных файлов LaserWar — только готовые модифицированные `.bin`.

## Как прошить

1. Прошейте тагер модифицированным `.bin` тем же способом, которым обычно обновляете прошивку LaserWar (конфигуратор / штатная процедура обновления).
2. Для управления «Зомби» и ID прошейте пульт модом из репозитория выше (сборка `--zombie-test` / актуальный релиз с меню Зомби и ID).
3. Вернуть официальную прошивку тагера можно, прошив оригинал с https://laserwar.ru/firmware-for-hardware/
